# Supabaseの準備

1. Supabaseのダッシュボード https://supabase.com/dashboard でログインし、新しいプロジェクトを作成する。
2. プランはまずFreeを検討し、表示される最新の制限と料金を確認する。リージョンは日本に近い場所を選ぶ。
3. DBパスワードはパスワードマネージャーに保管し、チャットやGitへ貼り付けない。
4. プロジェクトが起動したらConnectまたはAPI設定でProject URLとpublishable keyを確認する。
5. 開発環境の環境変数に VITE_SUPABASE_URL と VITE_SUPABASE_PUBLISHABLE_KEY を設定する。publishable keyはフロントエンド公開用。secret / service_roleキーは使用しない。
6. プロジェクト作成が完了したことを開発担当へ伝える。個別の接続先ホストをネットワーク許可設定に追加する必要がある。

以後、開発担当がDBマイグレーションと適用手順を準備する。
Authの一般サインアップ無効化、所有者ユーザー作成、認証URL設定は実装に合わせて行う。
既存データがないことを確認してからマイグレーションを適用する。
