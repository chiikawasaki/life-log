# UIのトーン＆マナー

Nani翻訳の入力中心の構成、淡い色面、大きな角丸、親しみやすい短い言葉を参考にする。配色はプロダクトオーナーの指定に従い、白とピンクを維持する。

- 白をベースに、薄いピンクの入力エリアとローズの主操作ボタンを使う。
- ホームは記録フォームを主役にし、PCでは成長の一覧を右に、スマホではフォームの後に置く。
- ステータスは独立した6枚のカードではなく、一つの一覧にまとめる。
- カードは24px、入力は16pxの角丸。ナビゲーション・ボタン・タグはカプセル型。
- グラデーション、強い影、英語の装飾見出し、大きな数値の演出は使わない。
- アイコンは単色の線画。絵文字は記録後のひとことに控えめに使う。
- キーボードフォーカスを見えるようにし、動きを減らす端末設定にも対応する。
- 保存、エラー、確認の文言は短く、操作結果が分かる自然な日本語にする。

記録・集計・認証・DBの仕様は既存の要件を維持する。
