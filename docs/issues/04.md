# ステータスと総合経験値の表示

確定したルールに沿う純粋な集計関数とホーム画面を実装する。

## 受け入れ条件
初期6ステータス、経験値、レベル、次レベルまでの進捗が表示される。数量とレベルの境界値テストが通る。

## 参照
REQUIREMENTS.md、docs/DESIGN.md、docs/TASKS.md

## 優先度と依存
P0。03。15経験値ごとのレベルアップで確定。レベル = 1 + floor(総合経験値 / 15)。経験値0・14・15・29・30の境界を検証する。

## MVPの共通方針
個人用。努力の記録と経験値の可視化に限定し、人生計画は対象外。知識・体力・コミュ力・芸術・生活力・副業の6ステータス。白とピンクのシンプルな管理画面。スマホ・PCに対応し、Supabaseで認証・保存する。
