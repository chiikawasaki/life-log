# 結合検証・コードレビュー・PR

MVPの受け入れ条件を実測し、差分をレビューしてPRを作成する。

## 受け入れ条件

360pxとPCで操作可能。同じアカウントの別セッションで保存記録を取得できる。型チェック・テスト・ビルド結果と未検証項目をPRに記載する。

## 参照

REQUIREMENTS.md、docs/DESIGN.md、docs/TASKS.md

## 優先度と依存

P0。01〜05。実際のSupabase接続が必要。

## MVPの共通方針

個人用。努力の記録と経験値の可視化に限定し、人生計画は対象外。知識・体力・コミュ力・芸術・生活力・副業の6ステータス。白とピンクのシンプルな管理画面。スマホ・PCに対応し、Supabaseで認証・保存する。
