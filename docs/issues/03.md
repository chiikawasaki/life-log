# 行動ルールと努力記録

行動ルールの作成・版管理・アーカイブ、日付・数量・メモの記録を実装する。

## 受け入れ条件
必要量とポイントを設定できる。不正値を拒否し、再送で重複しない。保存失敗時に入力が残る。

## 参照
REQUIREMENTS.md、docs/DESIGN.md、docs/TASKS.md

## 優先度と依存
P0。02。勉強時間はまとめて手入力し、初期ルールは120分で知識+1。端数持ち越しと「あと何分で+1」の表示は推奨案として提案中。

## MVPの共通方針
個人用。努力の記録と経験値の可視化に限定し、人生計画は対象外。知識・体力・コミュ力・芸術・生活力・副業の6ステータス。白とピンクのシンプルな管理画面。スマホ・PCに対応し、Supabaseで認証・保存する。
